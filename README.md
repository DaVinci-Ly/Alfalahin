# موقع شركة الفلاحين الحديثة لصناعة الأعلاف ذ.م.م

الموقع التعريفي الرسمي لـ **شركة الفلاحين الحديثة لصناعة الأعلاف ذ.م.م** (سيلين، الخمس، ليبيا).
ملفات ثابتة (HTML / CSS / JavaScript) بدون أدوات بناء، جاهزة للنشر على GitHub Pages.

---

## ما يحتويه الموقع

- أربع صفحات: الرئيسية، المنتجات، عن الشركة، تواصل معنا (+ صفحة 404).
- نسخة إنجليزية في مجلد `en/` بنفس الصفحات (اتجاه LTR)، وزر AR/EN في الترويسة ينقل إلى نفس الصفحة باللغة الأخرى.
- الشعار: `assets/img/logo-128.png` (الترويسة والتذييل) و `assets/img/logo-480.png` (الواجهة)، نسخ مصغّرة من `logo.png`.
- الرسومات: `hero-mill.svg` (المصنع والحقل)، أيقونات المنتجات `icon-*.svg`، وزخرفة السنابل `deco-wheat.svg`.
- الخطوط محلية: GE SS Two للعناوين، و IBM Plex Sans Arabic للنصوص.
- في الهاتف: زر اتصال وزر واتساب في الترويسة، وشريط تنقل سفلي بأربع صفحات.
- نموذج طلب السعر يجهّز رسالة ويفتحها في واتساب على الرقم `0927144064`.
- موقع المصنع على الخريطة: `https://maps.app.goo.gl/Mk593WjEitY1s3hG9` (32.638081, 14.155843).

---

## تشغيل الموقع محلياً

الموقع ملفات ثابتة نقية، لا يحتاج إلى `npm install` أو أدوات بناء معقدة.
لتشغيله محلياً عبر بايثون:

```bash
python3 -m http.server 8080
```

ثم افتح في المتصفح: <http://localhost:8080>

## النشر على GitHub Pages وربط النطاق

النطاق الرسمي المعتمد للموقع هو `www.alfalahin.ly` (ملف `CNAME` يحتوي عليه)، وجميع الروابط الداخلية وبيانات SEO في الموقع تشير إليه بهذا الشكل بالضبط.

1. في إعدادات المستودع على GitHub:
   - اذهب إلى **Settings** > **Pages**.
   - اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.
2. في لوحة تحكم نطاق `alfalahin.ly` (مزود النطاق الليبي)، أضف كل السجلات التالية معاً:
   - سجل **CNAME** لـ `www` يشير إلى `davinci-ly.github.io`.
   - سجلات **A** للنطاق الأساسي (بدون www) تشير إلى خوادم GitHub Pages:
     - `185.199.108.153`
     - `185.199.109.153`
     - `185.199.110.153`
     - `185.199.111.153`
   - بوجود هذين معاً، يقوم GitHub تلقائياً بتحويل من يدخل `alfalahin.ly` (بدون www) إلى `www.alfalahin.ly`، فلا تضيع أي زيارة.
3. في **Settings > Pages** بعد ظهور النطاق، فعّل **Enforce HTTPS** (يحتاج بضع دقائق لإصدار شهادة SSL بعد إضافة سجلات DNS).
