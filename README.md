# موقع شركة الفلاحين الحديثة لصناعة الأعلاف ذ.م.م

الموقع التعريفي الرسمي لـ **شركة الفلاحين الحديثة لصناعة الأعلاف ذ.م.م** (سيلين، الخمس، ليبيا).
مبني بملفات ثابتة فائقة السرعة وخفيفة (HTML5 / Vanilla CSS / Vanilla JavaScript)، بدون أطر عمل خارجية، متوافق مع كافة مقاييس SEO ومحركات البحث، ومهيأ للنشر المباشر على GitHub Pages أو أي خادم ويب.

---

## الميزات والخصائص

1. **تصميم احترافي بشري**: مظهر صناعي رصين بألوان القمح الذهبي والكحلي الفاحم، دون أي صور مصطنعة بالذكاء الاصطناعي أو مصطلحات لغوية متكلفة.
2. **تجربة هاتف استثنائية (مستوحاة من بريق التاج)**:
   - شريط تنقل سفلي ثابت (`.tabbar`) بأيقونات عصرية تتوافق مع هواتف الآيفون والأندرويد.
   - زر واتساب مباشر في الترويسة العلوية لسهولة الطلب الفوري.
   - تذييل مخصص للهواتف يتجنب التكرار والازدحام.
3. **بيانات قانونية وصناعية موثقة رسمياً**:
   - السجل التجاري: `05060202426292`
   - السجل الصناعي: `2561/6`
   - الرقم الضريبي: `1792`
   - ترخيص مزاولة النشاط: `018-05060202426292` (بلدية الخمس)
4. **تغطية شاملة لمنتجات الأعلاف**:
   - أعلاف الدواجن (لحم وبيّاض)
   - أعلاف الأبقار والماشية (حلّاب وتسمين)
   - أعلاف الأغنام والماعز
   - أعلاف الإبل والهجن
   - الخلطات والتركيبات الخاصة
5. **الخطوط مستضافة محلياً**: خط **GE SS Two** بصيغة `woff2` الخفيفة لتوفير سرعة تحميل خارقة دون الاعتماد على خوادم خارجية.
6. **نموذج طلب عروض أسعار تفاعلي**: يجهز رسالة مرتبة تلقائياً وينقلها إلى محادثة واتساب الرسمية للشركة (`0927144064`).

## تشغيل الموقع محلياً

الموقع ملفات ثابتة نقية، لا يحتاج إلى `npm install` أو أدوات بناء معقدة.
لتشغيله محلياً عبر بايثون:

```bash
python3 -m http.server 8080
```

ثم افتح في المتصفح: <http://localhost:8080>

## النشر على GitHub Pages وربط النطاق

1. تم وضع ملف `CNAME` يحتوي على:
   ```
   alfalahin.ly
   ```
2. في إعدادات المستودع على GitHub:
   - اذهب إلى **Settings** > **Pages**.
   - اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.
3. في لوحة تحكم نطاق `alfalahin.ly` (مزود النطاق الليبي):
   - وجّه سجلات الـ A لنطاقك إلى خوادم GitHub Pages:
     - `185.199.108.153`
     - `185.199.109.153`
     - `185.199.110.153`
     - `185.199.111.153`
   - وسجل CNAME لـ `www` يشير إلى مستودعك.
